# Seeker Of SoundZ v4.5 Quick Start

1. Upload every file and folder to the public web root (`public_html`, `www`, or `htdocs`).
2. Keep the folder structure unchanged.
3. Enable HTTPS.
4. Open `index.html`.
5. Sign in with the demo admin only for testing, then replace demo/local authentication before production.

The static package stores accounts, forums and collaboration metadata in each browser. For a public multi-user deployment, connect a database, object storage and the included webhook backend starter.
