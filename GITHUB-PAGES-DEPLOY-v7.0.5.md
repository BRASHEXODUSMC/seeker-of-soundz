# Seeker Of SoundZ v7.0.5 — GitHub Pages deployment

## Important

The ZIP contains a hidden `.nojekyll` file. Keep that file in the repository
root. It tells GitHub Pages to publish the website exactly as supplied instead
of processing it through Jekyll.

## GitHub Desktop

1. Extract the ZIP.
2. Open your local Seeker Of SoundZ repository folder.
3. Copy all extracted files into the repository and replace older files.
4. In GitHub Desktop, confirm `.nojekyll` appears in the changed-file list.
5. Commit with: `Seeker Of SoundZ v7.0.5 build fix`
6. Push origin.
7. Open the repository’s **Actions** or **Deployments** area and wait for Pages.
8. Hard-refresh the website with `Ctrl+F5`.

No Supabase update is required.
