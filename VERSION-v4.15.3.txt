Seeker Of SoundZ v4.15.3
ACHIEVEMENT CHIMES, PROFILE SOUND SETTINGS, TOAST LAYER, NAVIGATION INTEGRITY

Added:
- A quiet synthesized chime plays for every realtime achievement notification.
- Quest reward claims use the selected achievement chime.
- Non-achievement realtime notifications use the selected notification sound.
- Profile Settings now includes achievement and notification sound selectors.
- Preview buttons and a volume slider are included.
- Sounds are generated by the website and require no copyrighted audio files.
- Available achievement sounds: Crystal Rise, Frequency Bloom, Starlight, Deep Signal.
- Available notification sounds: Soft Pulse, Digital Drop, Gentle Bell, Subtle Click.
- Each sound category can be disabled independently by selecting No Sound.
- All sounds can be disabled with the profile setting.

Fixed:
- Toast notifications now display above Frequency Progression and other modal layers.
- App shell no longer creates duplicate Cart or Account drawers if loaded more than once.
- Navigation integrity guard removes duplicate controls and duplicate page links.
- Account dropdown duplicate links/buttons are removed safely.
- Existing navigation layout, account links, profile module, quests, events, forums, and Supabase logic are preserved.

Storage:
- Sound preferences are stored privately in this browser profile using localStorage.
- No SQL patch is required.
