Video Effects Studio

Guided project tutorial

🎬

Start with footage

Use the Create module to upload a local video. This is the fastest and most reliable workflow in Chrome, Edge, and Firefox.

🎵

Add licensed music

Upload an audio file you are allowed to use. The direct composer replaces or mixes the source audio and renders it into the finished project.

✨

Choose effects

Open Effects, select a preset, and watch the compact preview. Presets no longer move the page or send you to another section.

📚

Find reusable assets

The Libraries module links to official licensed stock-video and music sources. Always review the individual asset license before publishing.

⬇

Render and download

Open Export and select Build Finished Video. The browser records the processed canvas with the uploaded soundtrack.

🖥️

Optional screen capture

Capture is separate and optional. Chrome or Edge is recommended for tab audio. Firefox can capture screens, but audio availability varies by operating system and source.
